Shraddha Dodke - Portfolio
==========================

Files
-----
index.html                  The whole portfolio (photo, resume preview, chatbot and styles are all inside this one file).
Shraddha_dodke_resume.pdf   Your resume PDF, kept here for sharing or uploading.

Run it on your computer
-----------------------
Double-click index.html. It opens in your browser.
(Needs internet only to load the Manrope and Outfit fonts from Google Fonts; without internet it still works with fallback fonts.)

Put it online (free options)
----------------------------
1. GitHub Pages: create a repo, upload index.html, then Settings > Pages > deploy from the main branch.
2. Netlify Drop (app.netlify.com/drop): drag this folder onto the page.
3. Vercel or Cloudflare Pages: upload the folder as a static site.

Things you may want to edit (open index.html in VS Code or any editor)
----------------------------------------------------------------------
- Stats, project cards, contact links: search for the text and change it.
- Resume shown by "View my resume": it is an image embedded in index.html. If you update your resume, ask Claude to regenerate it.
